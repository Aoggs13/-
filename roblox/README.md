# LAVA RUSH — Лавадан қаш!

Roblox үшін шағын көпойыншылы obby: көтерілген лавадан қашып, 24 алаңмен мұнара шыңындағы порталға жет. Жалғыз да, достарыңмен де ойнауға болады.

## Бірден ашу

1. [dist/LavaRush.rbxlx](dist/LavaRush.rbxlx) файлын компьютерге ал.
2. **Roblox Studio** бағдарламасында **File → Open from File…** арқылы аш.
3. **Play (F5)** бас. Карта ойын басталғанда автоматты жасалады.
4. Нұсқаулықтағы **ОЙНАЙЫҚ!** батырмасын бас. Келесі раундқа автоматты қосыласың.

Roblox Studio Windows/macOS жүйелерінде қажет. Linux бұлтында Studio іске қосылмайды. Жоба Roblox-та жарияланбаған: Studio арқылы **File → Publish to Roblox** жаса. Тек өз аккаунтың арқылы кір; кодқа құпиясөз немесе токен қосудың қажеті жоқ.

## Қалай ойнайсың

- **WASD / джойстик:** жүру. **Space / секіру батырмасы:** секіру.
- **Q / геймпад X / СЕРПІЛУ:** алға серпілу, қайта қолдану аралығы — 4 секунд. Жиегіне жақын қолданғанда абайла.
- **Жасыл кристалл:** +3. Әр кристалды бір раундта бір рет жинайсың; басқа ойыншыларға да қолжетімді.
- **Жасыл портал:** жеңіс және +30 кристалл. Соңғы, 24-ші алаңнан өту керек.
- **Сары алаң:** басқаннан кейін 0,85 секундта құлайды, 2,3 секундтан кейін қалпына келеді.
- **ЖЫЛДАМДЫҚ+:** 30 / 65 / 110 кристаллға үш деңгей. Жылдамдық 18 → 20 → 22 → 24.

Раунд 95 секундқа дейін созылады. Алғашқы 12 секундта лава қозғалмайды. 20 секундтан ұзақ тірі қалғандарға +5; жеңгендер +30 алады. Марапат раунд соңында бір рет беріледі. Бәрі ұтылса немесе мәреге жетсе, раунд ертерек аяқталады. Құлағандар мен кейін қосылғандар лоббиде келесі раундты күтеді. Әр раундта жолдың бағыты, түстері және құлайтын алаңдары өзгереді.

## Прогресті сақтау

Studio-дағы сынақ пен жарияланбаған файл **тек осы сессияның** ұпайын сақтайды. Жарияланған ойында Roblox DataStore автоматты қолданылады; қолжетімсіз болса, ойын сессиялық режимде жалғасады және интерфейс соны көрсетеді. Деректі оқи алмаған сервер ескі прогресті жазып тастамайды. Серверлер арасында 180 секундтық сессия құлпы бар, автосақтау 60 секунд сайын және раунд соңында орындалады. Бұлттағы тесттер сақтау логикасын жалған DataStore арқылы тексереді; нақты Roblox DataStore қолжетімділігі әлі тексерілмеген.

## Осы бұлтта әзірлеу

Python 3, curl, unzip және Linux x86_64 қажет. Ботқа арналған тәуелділіктер бұл ойынға керек емес. Ешқандай API кілті қажет емес.

```bash
cd /workspace/-/roblox
bash tools/setup.sh
bash tools/check.sh
```

`setup.sh` ресми Luau 0.699 Linux жинағын HTTPS арқылы жүктейді, бекітілген SHA-256 мәнін тексереді және `/workspace/.tools/luau-0.699` ішіне орнатады. Орнату қайта орындала алады. Python жинағышының сыртқы тәуелділігі жоқ.

`check.sh` ойын ережелерін, толық раунд есебін, картаның геометриясын және сақтау құлыптарын тексереді; барлық Luau файлдарын компиляциялайды; таза модульдерді статикалық талдайды; `.rbxlx` пен бастапқы коды бар ZIP-ті қайта жасайды және экспортты тексереді. Тек қайта жинау:

```bash
python3 tools/build.py
```

`src/shared` ішіндегі файлдық `require("./Rules")` импорты жинау кезінде Roblox-тың Instance импортына айналады. Өзгерістен кейін `.rbxlx` файлын қайта құрып, Studio-да жаңадан аш. Орындалатын сервер бұлтта қажет емес; ойын серверін Studio **Play** іске қосады.

## Тексерілгені және Studio-да тексерілетіні

Бұлтта 34 Luau мінез-құлық тексеруі және экспорттың 3 Python тексеруі өтеді. Сервер мен интерфейс компиляцияланады. Бұл 3D физиканы немесе экрандағы көріністі тексеру емес.

Studio-да жарияламас бұрын:

1. **Play:** лобби → кері санау → мұнара → лаваға құлау → келесі раунд.
2. 24-ші алаңнан порталға жет: бір жеңіс пен +30 бір рет берілсін.
3. Бір кристалды қайта бас: қосымша ұпай берілмесін. 30 кристаллмен бірінші жақсартуды сатып ал.
4. **Test → Server & Clients** арқылы екі ойыншыны қос: екеуі бір кристалды бөлек жинасын, бірінің өлімі екіншісін тоқтатпасын.
5. **Device Emulator** арқылы телефонның тік/көлденең экранында жүру, секіру және серпілу батырмаларын тексер.
6. Жарияланған жеке сынақ ойынында шығып-қайта кіріп, прогрестің сақталуын тексер.

## Файлдар

- `src/server/Main.server.luau`: карта, раунд, лава, қозғалыс қабілеті және серверлік тексерулер.
- `src/server/ProfileStore.luau`: сақтау және сессия құлпы.
- `src/shared/Rules.luau`, `GameState.luau`, `MapPlan.luau`: тексерілетін таза логика.
- `src/client/Main.client.luau`: қазақша интерфейс, нұсқаулық, пернетақта/геймпад/сенсор басқаруы.
- `dist/LavaRush.rbxlx`: Studio-да ашылатын дайын файл.
- `dist/LavaRush.zip`: дайын файл және бүкіл бастапқы код.
