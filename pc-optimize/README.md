# Пинг + FPS оптимизациясы (Windows 10/11)

## Іске қосу
1. ZIP-ті шығар: оң батырма → **Extract All / Извлечь все**.
2. **`Optimize.bat`** екі рет бас → «Иә» (әкімші рұқсаты).
   SmartScreen шықса: **More info / Подробнее** → **Run anyway / Выполнить в любом случае**.
3. Біткен соң компьютерді **қайта қос**.

Қайтару: **`Restore.bat`** — бәрі бастапқы күйге оралады. Өшірілген қолданбаларды ғана
Microsoft Store-дан қолмен қайта орнату керек.

## Не істейді
| Қадам | Не үшін |
|---|---|
| Қуат режимі → Ultimate / High Performance | CPU жиілігі түспейді → FPS тұрақты |
| Game Mode қосу, Game DVR (фондық Xbox жазба) өшіру | фондағы видео-жазба FPS жемейді |
| Ойындарға CPU/GPU басымдығы (MMCSS) | ойын фондық процестерден бұрын |
| Network throttling өшіру, Nagle өшіру, DNS кэш тазалау | желі пакеттері кешікпей кетеді |
| Windows Update-ті басқа ПК-ларға таратуды өшіру | upload арнасы бос → пинг секірмейді |
| Телеметрия (DiagTrack) өшіру | фондық жүктеме аз |
| Алдын ала орнатылған жарнамалық қолданбаларды өшіру | Bing News/Weather, Solitaire, Clipchamp, Candy Crush т.б. (Xbox, Store, Photos тиілмейді) |
| Temp тазалау | диск орны |
| Тексеру | Wi-Fi/кабель, фондағы интернет жейтін бағдарламалар, автозагрузка, пинг тесті |

Әр өзгерістің бастапқы мәні `C:\ProgramData\PingFpsTweak\backup.json` ішінде сақталады.

## Шынын айтқанда
- **Пинг** ең алдымен серверге дейінгі қашықтыққа, провайдерге және **Wi-Fi/кабельге** байланысты.
  Скрипт пингті «нөлге» түсірмейді — фондағы кедергілерді алып, **секіруін (spike)** азайтады.
- **FPS** өсімі жүйеге байланысты: ноутбук/әлсіз ПК-де байқалады, қуатты ПК-де аз.

## Ойын ішінде (ең көп әсер)
- **LAN кабель** — Wi-Fi-дан әлдеқайда тұрақты.
- **VSync өшір**, FPS лимитін монитор Гц-іне тең қой.
- **NVIDIA Reflex → On + Boost** (бар болса).
- Видеокарта драйверін жаңарт (NVIDIA App / AMD Adrenalin).
- Ойында **ең жақын серверді** таңда.
- Ойнағанда торрент, Steam/Epic жүктеулерін, Windows Update-ті тоқтат.
